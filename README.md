# DYSOBAY — homepage redesign

Art-directed homepage concept for DYSOBAY (Dubai, one-of-one womenswear — "Not Mass Approved").

## Contents

- `index.html` — self-contained build. Open it directly in a browser; all images and fonts are inlined, no server or network needed. This is what GitHub Pages should serve.
- `src/DYSOBAY Homepage.dc.html` — editable source (single streaming component file, inline styles only).
- `src/support.js` — runtime required by the source file.
- `src/img/` — DYSOBAY campaign and brand assets used by the design.

## Design direction

Foundation is off-white `#F3F2EE` + near-black `#090909`. DYSOBAY orange `#F05A0A` and electric blue `#2537C8` appear only as interventions, never as decoration. Deep red `#8F2025` is reserved for the Geisha Uprising story.

Type: Bricolage Grotesque (structure), Martian Mono (coordinates, labels, system voice), Shantell Sans (the hand — annotations and manifesto).

Named moments, in order:
1. Barcode rule + off-axis header; the blue brush X crosses out the hero and the garment is cropped through it.
2. A near-silent band — two lines and one margin note.
3. **The Index** — the collection *is* a barcode. Hover a bar to scan a piece; claimed pieces are struck out with the real brush X.
4. Geisha Uprising — headline in deep red crossing the photograph, hangtag rotated into the margin.
5. Manifesto — black ground, the coordinates 4.25.19.15.2.1.25 on a deliberately irregular grid.
6. Haifa's 3am story in a narrow column, packaging shown as evidence.
7. Orange casting interruption, then a footer that admits it is unfinished.

## Notes

Prices, sizes and copy details are placeholders pending real product data. Cart, forms and secondary pages (piece detail, full manifesto) are not built.
